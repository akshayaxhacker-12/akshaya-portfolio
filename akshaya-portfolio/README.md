# Benduri Akshaya - Portfolio

Static website (HTML, CSS, JavaScript). No installation or build step needed.

## Files
- index.html  - page content
- style.css   - styling (light and dark mode)
- script.js   - phishing risk-score demo
- assets/Benduri_Akshaya_Resume.pdf - your one-page resume

## Run in VS Code
1. Unzip the folder and open it in VS Code (File > Open Folder).
2. Install the "Live Server" extension (by Ritwick Dey).
3. Right-click index.html and choose "Open with Live Server".

Without Live Server: double-click index.html to open it in your browser.
Internet is needed only for the Google Fonts; the page still works offline with fallback fonts.

## Edit
Change text in index.html, colors in the :root block at the top of style.css.
